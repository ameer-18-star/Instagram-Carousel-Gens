Hack #01

Active Recall: The Retrieval Protocol

  1. 1
    Study for 25 minutes Focused input session — no distractions, phone away.
  2. 2
    Close everything Shut the book. Turn off the video. Total blank slate.
  3. 3
    Write what you remember Brain dump every concept — forces retrieval, not recognition.
  4. 4
    Check & fill gaps Compare to source. Only the gaps need re-studying.
  5. 5
    Repeat after 24h, 3d, 7d Spaced intervals lock it into long-term memory permanently.

Hack #07
Cognitive Load Theory — Sweller, 1988

Reduce Cognitive Load Instantly

  • 01
    Chunk Information Break content into 3–5 item groups. RAM can only hold ~7 items at once.
  • 02
    One Screen, One Task Multitasking reduces IQ by 10 points temporarily. Single-task always wins.
  • 03
    Pre-Study Brain Dump Write all distracting thoughts before starting. Clears working memory bandwidth.
  • 04
    Use Schemas (Mental Models) Link new info to existing frameworks. Reduces load by up to 60%.
  • 05
    Audio + Visual = Double Encoding Dual channel theory: images + words processed in parallel for deeper memory.
